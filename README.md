☀️ SunCart – Summer Essentials Store
SunCart is a modern summer-themed eCommerce platform designed for users to explore and purchase seasonal products like sunglasses, outfits, skincare, and beach accessories. This project is a Single Page Application (SPA) built with the Next.js App Router.

🌟 Key Features
Modern Summer Theme: A unique design tailored specifically for seasonal shopping.

Fully Responsive: Optimized for a seamless experience across Mobile, Tablet, and Desktop devices.

Secure Authentication: Powered by BetterAuth, featuring secure Login, Registration, and Google Social Login.

Protected Routes: Product details are only accessible to authenticated users.

User Profile Management: Users can view their profile data and update their information (Name and Image).

Persistent Layout: Features a consistent Navbar and Footer across all routes.

🛠️ Tech Stack & Tools
This project utilizes modern web development technologies to ensure performance and security:

Core Technologies
Next.js (App Router): The primary React framework for routing and server-side rendering.

Tailwind CSS: For rapid and responsive UI styling.

DaisyUI / HeroUI: For pre-designed, accessible UI components.

BetterAuth: For handling sessions and secure user authentication.

MongoDB: Used as the database for storing user and product information.
